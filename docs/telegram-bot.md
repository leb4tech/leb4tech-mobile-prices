# بوت رفع قوائم الأسعار — إعداد مرة واحدة

الخدمة مضافة في services/telegram-bot. تعمل على Cloudflare Worker مع Durable Object لتخزين المسودة ومعالجة الصورة بعد استلامها. لا تحتاج تشغيل كمبيوتر أو تثبيت Python. لم تُفعّل الخدمة على حساب حقيقي ولم تُجرّب قراءة صورة حقيقية عبر API في بيئة التطوير، لأن المفاتيح والحسابات غير مهيأة. اختبارات محلية ومحاكي Cloudflare تغطي تدفق المعاينة والاعتماد والنشر؛ لا تثبت جاهزية الحسابات الخارجية.

## قبل التفعيل

- حساب Cloudflare يسمح بتشغيل Workers وSQLite Durable Objects وAlarms. راجع حدود الخطة والتكلفة؛ لا يُفترض أن كل الاستعمال مجاني.
- حساب OpenAI API بمفتاح مشروع يدعم Responses API وقراءة الصور وStructured Outputs. اشتراك ChatGPT وحده لا يتضمن رصيد API. الخدمة الافتراضية gpt-4.1-mini ويمكن تغيير OPENAI_MODEL في wrangler.jsonc بعد التحقق من التوافق. ضع ميزانية وتنبيهات استخدام في حسابك.
- يتم إرسال الصور إلى Telegram ثم OpenAI لقراءتها. يطلب الكود store=false لاستجابة OpenAI، وهذا لا يعني ضمان انعدام كل احتفاظ لدى مزود الخدمة. لا ترسل صورًا حساسة أو معلومات أشخاص غير لازمة. الخدمة لا تنسخ الصورة إلى المستودع؛ تُحفظ المسودة مؤقتًا في Cloudflare حتى الاعتماد أو الإلغاء أو انتهاء الصلاحية.

## 1. إنشاء البوت

افتح Telegram وابحث عن **@BotFather** الرسمي الموثق، ثم أرسل /newbot واتبع التعليمات لاختيار الاسم واسم المستخدم. احتفظ بالـToken في مكان آمن؛ لا ترسله في هذه المحادثة، ولا تضعه في ملف أو تعليق GitHub أو رابط متصفح. استخدم المحادثة الخاصة مع بوتك، وليس مجموعة.

## 2. إعداد GitHub Secrets

في مستودع leb4tech-mobile-prices افتح Settings → Secrets and variables → Actions → New repository secret. أضف:

| الاسم | القيمة ومصدرها |
| --- | --- |
| TELEGRAM_BOT_TOKEN | رمز البوت من BotFather |
| OPENAI_API_KEY | مفتاح مشروع OpenAI API الخاص بقراءة الصور |
| CLOUDFLARE_ACCOUNT_ID | Account ID من لوحة Cloudflare للحساب الذي سيستضيف Worker |
| CLOUDFLARE_API_TOKEN | API Token مقيّد بحسابك، بصلاحيات نشر Workers، مثل قالب Edit Cloudflare Workers؛ لا تستخدم Global API Key |
| BOT_GITHUB_TOKEN | Fine-grained personal access token للمستودع المحدد فقط، بصلاحيات Contents: Read and write وActions: Read and write، وMetadata: Read |

إنشاء GitHub token: إعدادات حساب GitHub الشخصية → Developer settings → Personal access tokens → Fine-grained tokens. حدد المستودع فقط وتاريخ انتهاء مناسبًا. لا يلزم Administration أو تجاوز حماية الفرع. إذا كانت قواعد main تمنع الكتابة المباشرة، فسيفشل الحفظ بأمان؛ هذه النسخة لا تتجاوز الحماية ولا تنشئ PR تلقائيًا.

لا تحتاج إلى توليد Webhook secret يدويًا: سير الإعداد يشتقه بمفتاح HMAC من Bot token ويخفيه في السجلات، ثم يحفظه كسر داخل Cloudflare ويستخدمه لتسجيل Webhook. يمكن للمستخدم المتقدم إضافة TELEGRAM_WEBHOOK_SECRET عشوائي اختياري بطول 32–256 من A-Z وa-z و0-9 و_ و-، وعندها يُستخدم بدل الاشتقاق.

## 3. النشر الأول وتحديد حساب المالك

1. ادمج التغييرات بعد نجاح Validate application.
2. استبدل محتوى Blogger بملف blogger/page.html الجديد مرة واحدة؛ الواجهة الجديدة تقبل نوع القوائم المعتمدة من البوت أيضًا. تبقى الصفحة بسيطة دون أزرار رفع أو عبارات تقنية.
3. من Actions شغّل **Deploy Telegram price bot → Run workflow** على main. سيُنشر Worker وتُضبط الأسرار ويُسجل عنوان Webhook تلقائيًا. لا تشغله من فرع غير موثوق، ولا تسمح لأشخاص غير موثوقين بتعديل الكود الذي يستعمل المفاتيح.
4. افتح بوتك وأرسل **/id**. سيرد بمعرف Telegram الرقمي الخاص بحسابك. قبل ضبط المالك، لن تُقبل الصور للنشر.
5. أضف الرقم كـGitHub Secret باسم **TELEGRAM_OWNER_ID**، ثم أعد تشغيل **Deploy Telegram price bot**. سيُقبل هذا الحساب فقط للرفع والاعتماد؛ تغيير الاسم الظاهر أو اسم المستخدم لا يمنح صلاحية.

القيمة الافتراضية للمالك 0، لذلك لا يمكن لأي حساب استغلال أول نشر لنشر الأسعار. أمر /id يرد لكل مستخدم خاص بمعرفه هو فقط، ولا يكشف المعرف المسموح أو يعطيه صلاحية. تُرسل تحديثات Telegram بالتتابع، ويُتجاهل تكرار update_id. إعادة تشغيل إعداد Webhook تتخلص من تحديثات Telegram القديمة المعلقة؛ المسودة الحالية في Cloudflare لا تُنشر دون اعتماد.

## 4. الاستعمال اليومي

أرسل الصورة إلى البوت كصورة أو مستند JPEG/PNG/WebP، بحجم 6MB أو أقل. إرسالها كملف يحافظ على وضوح النص. ضع في تعليقها تاريخ القائمة الحقيقي، USD، ورابط مصدر عام على سطر واحد، مثل:

```text
2026-10-23 USD https://www.facebook.com/photo?fbid=1548705240625052&set=a.550296653799254
```

هذا مثال للقائمة الأصلية، وليس تاريخًا يُنسخ لكل قائمة جديدة. لا تستخدم رابط ملف Telegram الذي يحتوي Token أو أي رابط يحمل مفاتيح أو بيانات دخول. الرابط للاستشهاد فقط؛ البوت لا يجلب منشورات Facebook ولا يتجاوز قيود المواقع.

سيرجع البوت ملف **prices-preview.csv** بكل الصفوف، ومعاينة نصية كاملة داخل Telegram دون الحاجة إلى Excel، والتاريخ والعملة والرابط، وزرين: **اعتماد ونشر** و**إلغاء**. افتح الملف وراجع الأسماء والأسعار وعدد الصفوف كاملة؛ تحقق خصوصًا من السعات والصفوف المتجاورة. OCR قد يخطئ حتى لو اعتبر السطر واضحًا. لا يتم تفسير PM أو Mix أو استكمال مواصفات أو افتراض توفر أو حالة الأجهزة.

الاعتماد يبدل القائمة المعروضة كاملة بآخر قائمة معتمدة؛ لا يدمج قائمتين ولا يحتفظ بصفوف قديمة على أنها حديثة. تأكد أن الصورة تحتوي القائمة الكاملة التي تريد عرضها. إذا كانت الصورة غير واضحة أو توجد أرقام مفقودة أو تكرار أو تعارض مع تاريخ التعليق أو عملته، تُرفض العملية كلها. لا توجد خاصية تعديل الصفوف داخل Telegram حاليًا؛ أرسل نسخة أوضح أو حدّث الملف يدويًا عبر مسار المراجعة المعتاد.

بعد الاعتماد يُحدث البوت **data/image-prices.json فقط** عبر GitHub API، مع مقارنة SHA لمنع الكتابة فوق تحديث متزامن، ثم يطلب تشغيل **Publish static index**. رسالة «حُفظت القائمة وبدأ طلب النشر» لا تعني اكتمال GitHub Pages؛ انتظر نجاح Actions ثم حدّث صفحة الموقع. إذا نجح الحفظ وفشل طلب النشر، سيطلب تشغيله يدويًا. لا تعدّل Blogger مع كل قائمة.

المعاينة صالحة 6 ساعات، وتُرفض الأزرار القديمة أو الملغاة أو المستخدمة. صورة جديدة بعد انتهاء المعالجة تلغي صلاحية معاينة الصورة السابقة. لا تُقبل صورة أخرى أثناء القراءة أو النشر؛ انتظر. /status يوضح آخر حالة، و/help يشرح طريقة الإرسال. لا توجد إعادة محاولة آلية عند فشل API، لتجنب نشر مكرر أو تكاليف قراءة إضافية دون علمك.

## الصيانة والتوقف

- عند فشل OCR يبقى ملف الموقع السابق. عند فشل GitHub تحقّق من انتهاء المفتاح أو الصلاحيات أو حماية الفرع؛ لا ترسل نص أخطاء يحتوي أسرارًا. في انقطاع الاتصال أثناء الحفظ قد يكون GitHub سجّل التحديث بالفعل، لذلك افحص آخر commit وActions قبل إعادة الاعتماد.
- لإيقاف البوت: Cloudflare → Worker → Settings → تعطيل الخدمة أو حذف Worker، ثم إلغاء المفاتيح التي لم تعد تحتاجها. إيقافه لا يحذف قائمة الأسعار المنشورة.
- لتدوير مفاتيح Telegram/OpenAI/GitHub غيّر GitHub Secret ثم أعد Deploy Telegram price bot. تجدد Webhook authentication تلقائيًا عند تغيير Bot token.
- للمطورين: npm ci ثم npm test من services/telegram-bot. الاختبارات تشمل SQLite Durable Object وAlarms عبر Miniflare، وطلبات API مقلدة. اختبار build دون نشر: npx wrangler deploy --dry-run.
- أبقِ بيانات المصدر وطريقة التفريغ داخل JSON للصيانة. لا تصف هذه القوائم كأسعار متحقق منها لدى الشركات أو كتوافر لحظي.
