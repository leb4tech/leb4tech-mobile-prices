# المصادر الدولية — أسعار البيع الحالية

## المصدر المفعّل: Google Store (الولايات المتحدة)

فحص 23 أكتوبر 2026: صفحات HTML عامة، وليست API مفترضة. القارئ GoogleStoreAdapter مخصص للبنية التي فُحصت؛ يتوقف إذا تغير الدليل أو انتهت مراجعة المصدر خلال 30 يومًا.

- سياسة الروبوتات: https://store.google.com/robots.txt تسمح بمسارات المنتجات والتهيئة المستخدمة. تُقرأ مجددًا كل تشغيل، وتُحترم قواعد wildcard وأولوية المسار الأطول. لا تُستخدم مسارات prices أو cart أو checkout المحظورة.
- صفحة الأسعار العامة: https://store.google.com/us/config/pixel_10?hl=en-US
- المواصفات الرسمية: https://store.google.com/us/product/pixel_10_specs?hl=en-US
- شروط المتجر التي فُحصت: https://store.google.com/intl/en-US_us/about/device-terms.html

النسختان المراجعتان: Google Pixel 10، لون Obsidian، سعتا 128GB و256GB، RAM 12GB، Unlocked، Dual eSIM، Google Tensor G5، وضمان Google لمدة سنة في السوق الأمريكية. لا تُفترض صلاحية الضمان في لبنان. الحالة جديدة بناءً على قناة البيع الرسمية القياسية وعنوان المنتج الجديد، وليست ادعاء بوجود حقل NewCondition غير موجود.

لكل نسخة وصف مطابق تمامًا في microdata مع USD وInStock. لا يكفي lowPrice في AggregateOffer وحده: يجب تطابقه أيضًا مع سعر الشراء الكامل الظاهر لزر السعة، دون أقساط أو استبدال أو اشتراك. تتوقف العملية إذا اختلف السعر أو السعة أو اللون أو شركة الاتصال أو الحالة أو دليل المواصفات. لا نختلق SKU؛ يستخدم هذا القارئ وصف النسخة الرسمي المميز بدلًا منه. لا تنسخ صورًا أو أوصافًا تسويقية.

الأسعار تُقرأ وقت التشغيل؛ لا توجد أسعار ثابتة في إعداد المصدر. ملف البيانات يسجل وقت الرصد. عرض واحد يعرض سعر Google Store فقط وaverage_usd=null؛ لا يُسمى متوسطًا عالميًا. السعر أمريكي بالدولار قبل الرسوم النهائية والشحن، وليس ضمان شحن المنتج إلى لبنان.

حقل permission_confirmed يسجل اكتمال مراجعة الوصول العام في هذا المشروع، وليس ترخيصًا خاصًا أو موافقة مكتوبة من Google على إعادة النشر. مراجعة robots وشروط البيع ليست إثباتًا شاملًا لكل شروط الخدمة؛ رابط الشروط العامة policies.google.com لم يُتح الوصول إليه في البيئة. يجب إعادة مراجعة السياسات وإيقاف المصدر عند أي منع جديد. لا يُستخدم تسجيل دخول أو وسائل تجاوز.

طلبات HTTPS مباشرة، User-Agent معرف مع رابط التواصل، مهلة 20 ثانية، حد استجابة 8MB لهذه الصفحات، وفاصل 5 ثوان على الأقل. تُجلب صفحة التهيئة والمواصفات مرة واحدة فقط للنسختين. لا إعادة محاولة عند 403 أو 429، ولا تتبع تحويلات. فشل أي نسخة أو نفاد مخزونها يمنع كتابة تحديث جزئي ويحفظ آخر لقطة سليمة ووقتها، مع تقرير فشل منفصل؛ التوفر المحفوظ يصف وقت الرصد السابق فقط.

## إضافة مصدر آخر

مصدر JSON-LD العام يستخدم kind=jsonld (أو الحقل الغائب للتوافق)، SKU مراجعًا وProduct/Offer صريحين. مصدر مختلف البنية يحتاج قارئًا واختبارات جديدة. تُراجع العملة USD مباشرة والسوق والمالك المستقل والموديل والسعة وRAM وSIM والحالة والضمان. متوسط حسابي يحتاج متجرين مستقلين للنسخة والسوق نفسيهما؛ لا أسعار صرف أو مواصفات تقديرية. الصور تتطلب إذنًا موثقًا. ملفات الاختبارات اصطناعية ولا تدخل النشر.
