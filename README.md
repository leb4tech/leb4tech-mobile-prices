# Leb4Tech — أسعار الهواتف

صفحة عربية RTL بالأبيض والأسود، تعرض اسم الهاتف وسعره بالدولار مع البحث وتصفية الشركة والحد الأقصى للسعر. أسماء الهواتف والاختصارات محفوظة كما وردت في القائمة. يعرض الزائر تاريخ القائمة ورابط المصدر وتنبيه تغير الأسعار؛ لا توجد أزرار إعادة تحميل أو قسم Google أو عبارات عن طريقة استخراج القائمة.

## الحالة الحالية

تعرض الصفحة 97 بندًا من القائمة المؤرخة في 23/10/2026. الأسعار بالدولار بتأكيد المستخدم. لا يثبت التفريغ توفر الأجهزة أو حالتها أو صحة هوية الموديلات لدى الشركات؛ لا تُضاف مواصفات تقديرية. أُوقف مصدر Google في config/sources.json بناء على طلب المستخدم، وتحتفظ ملفات البيانات القديمة بصيغتها للتوافق دون تحميلها في الواجهة الجديدة.

## الملفات

| الملف | الوظيفة |
| --- | --- |
| data/image-prices.json | القائمة المعروضة، بأسمائها وتاريخها ومصدرها الأصلي |
| schemas/image-prices.schema.json | مخطط مستقل للقائمة |
| price_index/image_list.py | فحص البنية والتكرار والأسعار والتاريخ |
| assets/image-prices.js وassets/app.css | العرض والبحث والتصفية والذاكرة المحلية |
| index.html | الصفحة المستقلة المولدة |
| blogger/page.html | محتوى مستقل جاهز للنسخ إلى Blogger |
| scripts/build.py | يولد الصفحة ومحتوى Blogger ومجلد site للنشر |
| scripts/validate.py | يتحقق من القوائم والبيانات المحفوظة |
| tests/ | فحوص البيانات والأمان والمتصفح وCORS |

ملفات global-phones.json وphones.json وapp.js وقارئ Google موجودة للتوافق والمراجعة؛ لا تُحمّل في الصفحة الحالية. بيانات الصورة مستقلة عن مخطط عروض المتاجر ولا تدخل في متوسط حسابي.

## التشغيل والاختبار

Python 3.12+:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m playwright install --with-deps chromium
python -m scripts.validate
python -m scripts.build
python -m http.server 8000 --bind 127.0.0.1
```

الاختبارات:

```sh
python -m unittest discover -s tests -v
```

إذا كان Chromium موجودًا، يمكن تحديد CHROMIUM_PATH=/usr/bin/chromium. تستخدم الاختبارات بيانات اصطناعية ولا تعيد كتابة الأسعار الحقيقية.

## النشر وBlogger

1. بعد نجاح Validate application ادمج التغييرات في main.
2. شغّل Actions → Publish static index → Run workflow. يجب أن يكون Settings → Pages → Source مضبوطًا على GitHub Actions.
3. انسخ كامل blogger/page.html من main إلى وضع HTML في صفحة Blogger واستبدل المحتوى القديم ثم احفظ. تغيير data-url وحده لا يزيل قسم Google من النسخة القديمة.
4. تحدّث الصفحة من رابط JSON العام الثابت دون تسجيل دخول:

https://leb4tech.github.io/leb4tech-mobile-prices/data/image-prices.json

رابط البيانات يولد من GITHUB_REPOSITORY أثناء البناء. تستخدم طلبات CORS دون credentials، ويجب أن يسمح المضيف العام بها. اختبارات المتصفح تفحص السماح والمنع من خادمين محليين مختلفين. عند فشل التحميل تُعرض آخر قائمة صحيحة محفوظة بتاريخها الأصلي إن كانت الذاكرة المحلية متاحة، وإلا تظهر رسالة خطأ مختصرة. يتطلب التحديث حينها تحديث الصفحة من المتصفح؛ لا توجد أزرار خاصة لإعادة التحميل.

## تحديث القائمة

حدّث data/image-prices.json بقائمة جديدة ثم نفّذ التحقق والاختبارات قبل اعتمادها، وانشر عبر Publish static index. لا حاجة لاستبدال HTML في Blogger عند تغيير البيانات فقط.

المصدر الأول صورة رفعها المستخدم من منشور Facebook. الأسماء منقولة دون تفسير PM أو Mix. استُبعد سطر مقطوع الاسم وجهاز لوحي وسُجل السببان في excluded. الصورة مقطوعة من الأسفل، لذلك لا تمثل القائمة جميع محتويات المنشور. المعلومات التفصيلية عن المصدر وطريقة التفريغ محفوظة في JSON للصيانة، دون عرضها كعناوين أو نصوص تقنية للزائر.

لا تغيّر list_date لمجرد إعادة رفع القائمة نفسها. لا تضف معلومات غير موثقة: availability وcondition تظلان null وmodel_identity_verified تظل false. لا تستعمل هذه البيانات لحساب متوسط أسعار متحقق منه. لا يوجد جلب تلقائي لفيسبوك أو OCR مجدول؛ تحديث الصفحة لا يبحث عن منشورات جديدة. سير Refresh verified prices يحتفظ بمساره القديم لكن مصدر Google معطل، ولا يعيد كتابة القائمة الحالية. تفعيل مصدر آلي آخر يحتاج مراجعة شروطه وإعدادًا منفصلًا؛ انظر docs/international-sources.md.
