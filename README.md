# Leb4Tech — أسعار الهواتف عالميا

واجهة عربية بالأبيض والأسود لعرض **أسعار البيع الحالية من متاجر دولية بالدولار الأمريكي**، مع ربط كل عرض بمصدره وسوقه ونسخته وتاريخ التحقق. ليست أسعار إطلاق، ولا أسعارًا مولدة بالذكاء الاصطناعي، ولا سعرًا موحدًا يضمن البيع في كل بلد.

**الحالة الحالية:** الواجهة والجمع المجدول والتحقق يدعمان الأسواق الدولية. أُضيف قارئ لصفحات Google Store الأمريكية العامة لنسختَي Pixel 10، بعد فحص بيانات السعة والسعر والتوفر والمواصفات. يعرض سعر متجر واحد دون ادعاء وجود متوسط سوق. [تفاصيل الفحص](docs/international-sources.md). لا توجد أسعار أو مواصفات وهمية منشورة.

## الملفات

| المسار | الوظيفة |

## قواعد العرض

- يظهر عرض متجر واحد كسعر متجر واحد، وaverage_usd يبقى null. لا ننتظر متجرًا ثانيًا لإظهار عرض صحيح، ولا نسميه متوسط سوق.
- يظهر المتوسط الحسابي فقط عند توفر متجرين مستقلين أو أكثر للنسخة والسوق نفسيهما. تشمل الهوية الماركة والموديل والسعة وRAM وSIM والحالة والضمان والبلد.
- لا تُدمج عروض بلدان مختلفة، حتى لو تشابه اسم الهاتف. لا يتم تحويل العملات؛ priceCurrency يجب أن تكون USD من المصدر نفسه.
- الرمز ≈ يوضح أن السعر مرجع متغير حسب عروض المتاجر وقت التحقق، وليس رقمًا مخترعًا أو قيمة محولة. الشحن والضرائب النهائية تحتاج تحقق لدى المتجر ولا يُدّعى أنها ضمن السعر.
- عند تغير عدد المصادر إلى متجر واحد، تُعرض أحدث تسعيرته دون الإبقاء على متوسط قديم وكأنه جديد.
- العروض الأقدم من 6 ساعات لا تدخل متوسطًا جديدًا. يمكن إبقاء آخر بيانات سليمة مع تحذير وتاريخها الأصلي عند فشل التحديث أو الشبكة.
- فشل مصدر أو التحقق يمنع اعتماد تحديث أسعار التشغيل. التقارير منفصلة، والحفظ ذري. لا يُعاد ضبط وقت نجاح السعر بمجرد تشغيل المجدول.
- المواصفات أو RAM أو الصور غير الموثقة لا تُختلق. RAM يمكن أن تكون null؛ حقول النسخة الأساسية لا يجوز ملؤها بقيم غامضة بغرض المطابقة.

## التشغيل المحلي

Python 3.12+:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m playwright install --with-deps chromium
python -m scripts.validate
python -m scripts.build
python -m http.server 8000 --bind 127.0.0.1
```

الاختبارات:

```sh
python -m unittest discover -s tests -v
```

مع Chromium الموجود في هذه البيئة:

```sh
CHROMIUM_PATH=/usr/bin/chromium python3 -m unittest discover -s tests -v
```

تحديث يدوي:

```sh
python -m price_index.refresh
python -m scripts.validate
```

دون مصادر مفعلة تكون النتيجة not_configured ولا يتغير ملف الأسعار أو تاريخ نجاحه. الاختبارات تستعمل بيانات اصطناعية داخل الذاكرة أو مجلدات مؤقتة فقط.

## GitHub Actions والنشر

1. ادمج التغييرات بعد نجاح Validate application. يلزم حفظ الملفات المولدة بعد تعديل الواجهة بتشغيل python -m scripts.build.
2. Refresh verified prices يحدث data/global-phones.json وتقرير الحالة كل 6 ساعات وفق cron UTC: `0 */6 * * *`. الجدولة بأفضل جهد، وقد تتأخر أو تتوقف للمستودعات غير النشطة وفق سياسة GitHub.
3. يمكن تشغيله يدويًا من Actions. يلزم سماح كتابة المحتويات لتسجيل ملفات البيانات. الدفع بلا force، ولا تُتجاوز قواعد حماية الفرع. لا حاجة لمفتاح Gemini.
4. التقرير محفوظ في Artifact باسم source-status. فشل الجمع يميز التشغيل بالفشل مع إبقاء آخر ملف أسعار سليم.
5. Settings → Pages → Source: GitHub Actions. شغّل Publish static index يدويًا لنشر الواجهة الجديدة أول مرة. يتابع أيضًا اكتمال التحديث لنشر آخر بيانات سليمة وتقرير الحالة.
6. مخرجات البناء في site/. تُبنى البيانات من اللقطات المتحقق منها؛ لا تنشر بيانات الاختبارات.

## تحديث صفحة Blogger الحالية

يلزم **استبدال محتوى صفحة Blogger بالكامل** بنسخة blogger/page.html الجديدة؛ تعديل data-url وحده لا يحدث منطق التحقق والعرض في النسخة القديمة.

للمستودع الحالي يكون رابط البيانات المتوقع بعد النشر:

```text
https://leb4tech.github.io/leb4tech-mobile-prices/data/global-phones.json
```

- انسخ blogger/page.html من النسخة المدمجة إلى وضع HTML في Blogger، ثم احفظ. رابط البيانات يولد من GITHUB_REPOSITORY عند البناء.
- ملف phones.json السابق باقٍ كما هو للصفحات القديمة؛ لا تُعاد كتابة تلك البيانات بصيغة لا يفهمها سكربتها.
- ضع status.json بجوار ملف الأسعار. كل النصوص بالعربية عدا أسماء الشركات والموديلات والمصطلحات التقنية اللازمة.
- تعمل ذاكرة محلية لآخر نسخة صحيحة إذا سمح المتصفح، مع تنبيه عند تعذر تحديثها. أول زيارة بلا بيانات محفوظة تعرض خطأ واضحًا.
- افحص الوصول العام دون تسجيل دخول وCORS بعد النشر:

```sh
python -m scripts.check_public_url https://leb4tech.github.io/leb4tech-mobile-prices/data/global-phones.json --origin https://www.leb4tech.com
```

الاستضافة يجب أن ترسل Access-Control-Allow-Origin مناسبًا. يدعم site/_headers استضافات مثل Cloudflare Pages؛ GitHub Pages لا يقرأ هذا الملف، لذلك اختبر رؤوسه الفعلية. لا تستخدم روابط GitHub blob لأنها HTML.

## اعتماد المصادر والصيانة

راجع [المصادر الدولية](docs/international-sources.md) و[شرح إعداد القارئ](docs/sources.md). الوثائق التي تتحدث عن مصادر لبنان تسجل مرحلة سابقة؛ country أصبح محددًا في إعداد كل مصدر، والخرج العالمي منفصل. راجع شروط الوصول وربط SKU (أو وصف النسخة الرسمي لقارئ Google Store) والنسخة كل 30 يومًا على الأكثر أو حسب شروط المتجر، مع احترام robots وحدود المعدل وTLS وعدم الالتفاف على حظر أو مصادقة.

كان الملف الأولي يحتوي مفتاح Gemini مكشوفًا؛ أُزيل، لكنه قد يبقى في تاريخ Git. ألغِه لدى مزوده، ولا تضع أسرارًا في Blogger أو ملفات JSON أو المحادثة.

## بيئة الاختبارات على GitHub

تستخدم اختبارات CI صورة Playwright الرسمية لإصدار Python 1.62.0 على Ubuntu Noble، مثبّتة ببصمة manifest، والمتوافقة مع إصدار Playwright في requirements-dev.txt. المتصفح واعتمادياته موجودة داخل الصورة؛ لا يتم تشغيل apt أو playwright install --with-deps في CI. هذا يتجنب التعطل السابق أثناء تنزيل حزم الخطوط. عند ترقية Playwright حدّث الصورة والبصمة والإصدار معًا. محليًا تبقى تعليمات التثبيت السابقة صالحة، أو استخدم Chromium الموجود عبر CHROMIUM_PATH.

تشغيل pull_request يتحقق من الفروع المقترحة، وتشغيل push يتحقق من main بعد الدمج، لتجنب تشغيل الاختبارات مرتين للفرع نفسه. المهلة الكلية 20 دقيقة تسمح بسحب الصورة، مع مهلة 5 دقائق مستقلة لتثبيت حزم Python ومثلها للاختبارات؛ لا يتم تخطي الاختبارات عند فشل الإعداد.

## قائمة الأسعار المصورة

أضيف قسم مستقل بعنوان «قائمة أسعار من صورة». ملفه `data/image-prices.json`، ومخططه `schemas/image-prices.schema.json`. المصدر صورة زوّد بها المستخدم من منشور Facebook بتاريخ 23/10/2026، والعملة USD بتأكيد المستخدم. نُقلت 97 تسمية وسعرًا دون تفسير PM أو Mix أو تحويل أسماء الموديلات إلى أسماء مصنعية. استُبعد سطر مقطوع الاسم وجهاز لوحي؛ وتُحفظ ملاحظتهما في excluded. لا تؤكد عملية التفريغ صحة تسميات المنتجات لدى الشركات.

هذا القسم لا يدخل في ملف global-phones.json أو المتوسط الحسابي، ولا يدعي التوفر أو الحالة أو بلد السوق أو ضمانًا متحققًا منه. عبارة الضمان منقولة من رأس الصورة فقط. يعرض التاريخ الأصلي والرابط والتنبيه عندما تكون القائمة من يوم سابق، ويتيح البحث والتصفية حسب القسم والسعر. إذا فشل التحميل، يحفظ آخر قائمة صالحة بتاريخها الأصلي إن كانت ذاكرة المتصفح متاحة. فشل هذا القسم لا يمنع عرض أسعار المتاجر.

**التفعيل:** بعد دمج التغييرات ونجاح الاختبارات، شغّل Publish static index. ثم استبدل محتوى صفحة Blogger بالكامل بمحتوى blogger/page.html الجديد من الفرع main، باستخدام وضع HTML. لا يكفي تغيير data-url في الصفحة القديمة؛ النسخة الجديدة تجلب image-prices.json من المجلد نفسه لرابط الأسعار. عنوان الملف العام بعد النشر:

https://leb4tech.github.io/leb4tech-mobile-prices/data/image-prices.json

**قائمة جديدة:** حدّث هذا الملف بتفريغ الصورة الجديدة، واحتفظ بتهجئة الأسماء، وتاريخ القائمة، ورابط المصدر الفعلي. لا تغيّر التاريخ لمجرد إعادة رفع الصورة نفسها. لا تملأ معلومات غير موجودة؛ availability وcondition تظلان null وmodel_identity_verified تظل false. نفّذ python -m scripts.validate ثم الاختبارات قبل الدمج، وانشر عبر Publish static index. سير عمل Refresh verified prices لا يعيد كتابة القائمة المصورة ولا يجلب Facebook. زر إعادة التحميل يقرأ ملف الموقع، وليس منشورات المتجر. لا يوجد في هذه الإضافة رصد تلقائي لفيسبوك أو OCR مجدول.
